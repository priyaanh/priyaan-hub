One-time setup for “Sign in with Google” (parent)

Reading events inside this page needs a Google API client ID. It takes about 5 minutes and is free:

  1. Go to console.cloud.google.com, signed in as the calendar's Google account, and create a project (any name, e.g. “Priyaan Hub”).
  2. APIs & Services → Library: enable the Google Calendar API.
  3. APIs & Services → OAuth consent screen: choose External, fill in the app name and your email, and add priyaan.haldiya@gmail.com (and any other family account) under Test users.
  4. Credentials → Create credentials → OAuth client ID, type Web application. Under Authorized JavaScript origins add https://priyaanh.github.io. Save and copy the Client ID (ends in .apps.googleusercontent.com).
  5. Paste it in the settings below. Sign-in only works on the hosted site, not when this file is opened from disk.
