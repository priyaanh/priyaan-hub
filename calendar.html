Your Google accounts

These are accounts you are signed in to. A calendar only appears if the account this browser is signed in as is allowed to see it, so adding someone else's address shows you nothing. Removing one here forgets it in this browser straight away.

The second calendar says “no permission”? Share it once

A browser can only show a private calendar for the account it is signed in as. Two ways to see several accounts at once:

  1. Share it (best). On the other account, open Google Calendar settings → Settings for my calendars → pick the calendar → Share with specific people or groups → Add people → enter the account you normally use here (for example ) → permission See all event details → Send. Accept the emailed invitation. It then shows up above.
  2. Or sign in to both. In Chrome, add both Google accounts to the browser profile (avatar → Add). Google shows calendars for whichever account is “first” in that browser, so sharing is the reliable option on shared devices.
  3. School or sports calendars that are public: paste the calendar's ID or its public address above instead of an email.

One-time setup for “Sign in with Google” (parent)

Reading events inside this page needs a free Google API client ID. About 5 minutes:

  1. Go to console.cloud.google.com, signed in as the main calendar account, and create a project (any name, e.g. “Family calendar”).
  2. APIs & Services → Library: enable the Google Calendar API and the Google Tasks API.
  3. APIs & Services → OAuth consent screen: choose External, fill in the app name and your email, and add every family Google account under Test users.
  4. Credentials → Create credentials → OAuth client ID, type Web application. Under Authorized JavaScript origins add https://priyaanh.github.io. Save and copy the Client ID.
  5. Paste it under Settings below. The same sign-in covers every calendar shared with that account and Google Tasks. Sign-in only works on the hosted site, not from disk.
